# Installed mod catalog (F6)

F6 and the native pause menu's Mods button open a searchable catalog: categories, descriptions, enable switches and pending-restart feedback. The original form renderer and its configured compact overlay hotkey remain unchanged. Unknown installed mods are listed too. `mod_settings` cannot switch itself off.

Install the updated `mod_settings` folder. No other new mod is required. Restart once to load the new entry point. Without live-lifecycle support the enable switches clearly require restart; with it they apply through the same saved settings. Existing settings.cfg is preserved. F6 closes the catalog and restores the previous pause state. The optional zone_fixes Escape feature returns to the pause hub instead.

Native validation: search by description, category filtering, save/readback and unchanged compact settings overlay. Controller drafts are protected when the optional Flight Desk is installed. Russian descriptions cover this repository's known realism mods. Newer third-party mods use a generic description.
